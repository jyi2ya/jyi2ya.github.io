VERSION

This describes version 0.20110617 of IkiWiki::Plugin::anypar

DESCRIPTION

Allows you to define any parameter of the pagetemplate (page.tmpl) using a template file; moreover, it allows you to use different template files for different sets of pages, as defined by a pagespec.

See doc/plugin/contrib/anypar.mdwn for documentation.
