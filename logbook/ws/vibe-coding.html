猛学 vibe coding 中。

之前在 VSCode 里用 kilocode vibe 了一下。发现如果直接用 code 模式的话它会很笨。可以先用 architecture 模式和它嘴炮一下实现意图和思路，它会给一个编写计划出来。非常有趣。之后可以仔细观察编写计划，然后修正它理解不对的地方。这样做之后 code 模式就基本上可以实现编程目标了。

问题在于它编写了一大坨东西，这一坨东西引用的代码东西也很多，逻辑很复杂。我让它给 Mojolicious 框架编写了一个新的 CGI 服务器。这个代码和框架其它部分交互很多，我也不确定里面有没有什么实现错误的地方……虽然它也能写一些测试倒是了。

试图彻底理解这一堆东西，并白盒地验证它能正确工作所需要的成本可能和我自己写一个新的差不了多少。即使测试能够部分证明它的正确性，万一实际用的时候出了问题查错也会很麻烦且低效。倒时候可能又是拿 LLM 来查 LLM 之前写的错误。

整个系统是没有人类专家兜底的，我觉得这种做法还是太激进了一点。

不过话又说回来，因为 LLM 不太偷懒，所以它测试可以做得很细致。天生就是 TDD 的好手。

另外写这堆东西的时候疑似并没有怎么用到编辑器。接下来可以试试把 vscode 拿掉直接使用炫酷的 tui 工具！
